# Phase 7 Limitations

- The engine is evidence scoring, not supervised ML.
- PCA materials directly support light bands and canopy transmission, but not the complete non-light numerical profiles.
- The Phase 3 feature set does not yet store mean temperature, so Phase 7 uses a bounded heat-stress-derived development proxy and discloses it.
- Row-orientation and canopy-density corrections are small bounded engineering assumptions.
- Pest conflict remains unconditioned when no Phase 6 run is supplied.
- Cacao and coffee figures are historical aggregate gross revenue, not net income.
- No candidate yield model is claimed because the uploaded income workbook does not provide validated crop-yield targets with complete reporting-period and cost definitions.
