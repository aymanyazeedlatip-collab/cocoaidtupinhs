# Formal Reports

Phase 10 generates DOCX and PDF reports containing:

- executive summary;
- component status;
- production and Bayesian uncertainty;
- pest, intercropping, and rehabilitation overview;
- complete six-scenario comparison;
- selected-scenario work plan;
- prioritized recommendations;
- evidence traceability;
- source provenance;
- limitations and safety boundaries;
- reproducibility information.

Each artifact stores a SHA-256 checksum and a canonical content fingerprint. Protected farmer identities and restricted raw files are excluded.

Public report metadata omits the internal filesystem path. Downloads are resolved only within the configured report directory.
