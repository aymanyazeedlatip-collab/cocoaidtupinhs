# Phase 9 User Actions

1. Install the release in a short folder.
2. Run `setup.bat` and `test.bat`.
3. Start `run.bat`.
4. Create one weather feature set, production forecast, and confirmed pest observation.
5. Run `run_phase9_workflow.bat` and paste the production forecast and observation UUIDs.
6. Preserve the generated record in `manual_test_outputs` for local verification only.
