# Phase 11 Limitations

- The coconut visualization is an SVG digital-twin interface element, not a botanical 3D scan.
- Map tiles and external weather layers still require their respective online providers.
- Browser autoplay policy may require the user to enter the workspace before music starts.
- The white theme is intentionally fixed for institutional consistency in this release.
- Phase 11 changes presentation, not field validation status or scientific accuracy claims.
