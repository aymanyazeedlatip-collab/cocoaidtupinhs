# Official Agri-Tech Design System

The interface uses solid white surfaces, restrained borders, compact shadows, and logo-derived colors:

- Dark green: `#246B32`
- Bright green: `#6FAE22`
- Orange: `#EF8500`
- Brown: `#724413`
- Primary text: `#172219`

Liquid glass, translucent cards, and blur-based panels are disabled. Gradients are limited to loading indicators, progress lines, scan lines, and grid-line construction. The interface stays in the official white theme; the previous dark-theme toggle is hidden.

Spacing, controls, cards, tables, maps, and chart containers use consistent border radii and paddings. Motion is slow and functional rather than decorative.
