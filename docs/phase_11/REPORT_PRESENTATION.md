# Official Report Presentation

The formal-report generator is now `formal-report-generator-1.1.0`.

DOCX output uses Times New Roman throughout, an official report title, document-control table, institutional header, analysis-record footer, and page numbering. PDF output uses the installed Windows Times New Roman font when available and Tinos or Times-compatible fallbacks elsewhere. PDF pages include a formal header, footer, page number, document-control page, and black-and-gray office styling.

The report content remains generated from stored analytical records rather than invented narrative values.
