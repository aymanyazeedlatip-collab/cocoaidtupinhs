# User Actions

1. Keep the Phase 7 folder as backup.
2. Extract Phase 8 directly into a short folder such as `C:\COCOAID\P8`.
3. Run `setup.bat` and confirm Phase 8 verification passes.
4. Run `test.bat` and confirm the final test count.
5. Run `check_weather_provider.bat`.
6. Start with `run.bat`.
7. Create weather and production records, then optionally create Bayesian, pest, and intercropping records.
8. Submit `POST /api/v2/rehabilitation/plan` using the exact payload in the release instructions.
