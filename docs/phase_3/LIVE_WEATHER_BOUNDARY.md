# Live Weather and Long-Term Simulation Boundary

## Live Weather GIS

The live subsystem displays:

- Current conditions
- Hourly and daily forecast values through Day 16
- Rainfall, temperature, humidity, cloud, pressure, wind, VPD, ET0, soil moisture, and solar variables when supplied

Any historical rows requested for feature engineering are removed from the user-facing live payload.

## Climate-Conditioned Farm Simulation

Dates beyond Day 16 are generated by the existing long-term stochastic/climate-conditioned subsystem. They must retain a distinct data-mode label and must not be called a live forecast.

## Enforcement points

- Pydantic requests reject `forecast_days > 16`.
- Grid/cube requests reject `forecast_hours > 384`.
- The normalizer clips oversized provider payloads.
- The live response strips historical values.
- Database constraints reject requested forecast horizons above 16 days.
