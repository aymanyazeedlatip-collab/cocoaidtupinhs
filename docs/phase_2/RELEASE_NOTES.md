# COCOAID v3 Phase 2 Release Notes

Phase 2 establishes the normalized PCA data foundation while keeping v2.11 analytical behavior intact. It adds a source-linked reference catalog, a privacy-separated farmer registry pipeline, migration 2, privacy-safe APIs, backup/restore tooling, and the HTTPX2 TestClient warning correction.

No Phase 2 reference data is claimed to be a trained machine-learning dataset. The farmer workbook is registry data and is not automatically imported.
