# COCO-AID v2.10.0 Release Notes

## Interface

- Light-theme preview entrance with the existing technology animation system.
- Desktop navigation can collapse to an icon rail and reopen without rearranging the workspace.
- Removed the sidebar logo descriptor.
- Settings now scrolls inside its own drawer.

## Audio

- Background music is requested as soon as the preview loads.
- Browsers that block unprompted audio can enable it by interacting anywhere on the preview.
- Music remains at a constant 10% volume and no longer ducks during voice lines.
- Removed Settings narration while retaining all tab, Weather GIS, and forecast-complete voice lines.

## Analytical scope

This release does not change mathematical, forecast, climate, production, pest, rehabilitation, database, report, or assistant calculations.
