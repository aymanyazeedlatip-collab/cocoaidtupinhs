# COCOAID Phase 11.3.14 — Event-Synchronized Intelligence and Automated Workflows

- Selected Threat now renders the exact representative Long-Term Model Forecast frame using the same rain renderer as Productivity.
- Bayesian pest pressure now exposes an event-conditioned display probability while preserving the raw Bayesian result for traceability. Rain/typhoon periods increase weather-conditioned pest pressure; dry/heat periods do not receive the wet-weather uplift.
- Event-conditioned land suitability now responds strongly to drought/heat through rainfall, temperature, drought exposure, and climate-stress inputs.
- Rehabilitation heatmap changed from circular blobs to square grid cells clipped to the drawn farm polygon.
- Decision-support Network, Reports, Database, and Methodology received interactive animated UI and shared automatic Phase 9 → Phase 10 status controls.
- A background workflow runner now starts Phase 9/10 automatically when eligible production forecast and observation records exist. No pasted IDs are required.
- CoCO-PILOT now has a semi-transparent spinning holographic sphere background with waiting, typing, loading, and speaking animation states.
