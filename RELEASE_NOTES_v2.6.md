# COCO-AID v2.6.0 - Liquid Glass Interface

This release changes the presentation layer while retaining the v2.5 arrangement and all existing analytical functionality.

## Interface

- Liquid-glass surfaces across navigation, cards, forms, dialogs, assistant, loading screen, and Weather GIS.
- Green/cyan refraction highlights, inner glass edges, controlled blur, dark smoked-glass mode, and graceful fallback when backdrop filtering is unavailable.
- Existing tab order, page structure, maps, charts, forms, and feature placement remain unchanged.

## Repairs

- Pest-specific outbreak heading and summary now stay inside the panel.
- The highest outbreak score card wraps correctly.
- Empty and generated pest-card states occupy the full available panel width without clipping.

## Branding

- Added the supplied Weather GIS icon to its floating button, modal, header, and favicon.
- Added the supplied CoCO-PILOT icon to its floating button and assistant header.
