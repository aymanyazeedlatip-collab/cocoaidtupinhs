# COCO-AID v2.11.0 Release Notes

This maintenance release repairs the navigation rail layout and improves its transition behavior without changing the application workflow.

## Changes

- Expanded navigation labels now use the remaining sidebar width instead of inheriting the 22-pixel icon width.
- Sidebar collapse/open uses a smooth 380-millisecond motion curve.
- Official branding, controls, API state, and labels transition together.
- Coconut-farm backgrounds remain cover-fitted while the workspace width changes.
- Leaflet maps are resized after the transition.
