# COCOAID Phase 11.3.5

Farmer-first frontend release with the existing Home section count preserved. Earlier coconut-farm photographs are reused as faded section backgrounds. The same Home sections now include farmer-useful model-response reference data, analytical-coverage graphics, and development-validation benchmark graphics. Development-set machine-learning metrics are explicitly identified as research benchmarks rather than field-validated accuracy claims.

Farm Profile is now a one-task-at-a-time workflow. The farm boundary map is the only task shown first and occupies the full setup area. After a valid boundary is confirmed, Basic Details opens automatically, followed sequentially by Tree Data, Soil & Care, and Tree Health. Future input stages stay hidden until needed. Each stage groups related questions and explains what information belongs there and why COCOAID needs it. Farm editing exposes a dedicated orange Save Farm Shape Changes action. Each polygon edge is labeled from Leaflet's geodesic distance calculation in kilometers. The farmer-entered replanting percentage has been removed; rehabilitation determines replanting need from the analytical workflow instead of asking the farmer to guess it.

The loading screen retains the COCOAID spinner and adds a small version of the existing alternating coconut/coconut-tree hologram. Loading status text is high-contrast orange.

Productivity is presented as Long-Term Model Forecast. For current runs, the first available provider horizon is explicitly labeled as genuine Open-Meteo numerical weather forecast data, while dates beyond that horizon are explicitly labeled climate-conditioned modeled weather. The production forecast continues to use the existing backend weather merge, so new provider weather is incorporated into matching near-term frames whenever the forecast is rerun. Scenario, intervention strategy, and run-count inputs are automatic and removed from the farmer-facing interface. The forecast map now fits the farm boundary with safer padding and a controlled maximum zoom. A compact on-map Weather GIS control provides Rain, Wind, and Farm overlays plus rainfall, temperature, humidity, cloud, and wind readouts from the current forecast frame. The full Weather GIS remains available below for deeper inspection and is synchronized to the same farm boundary. While Productivity remains open, COCOAID checks forecast freshness every five minutes and automatically re-runs forecasts that are at least 30 minutes old so newly available Open-Meteo data can refresh the provider window and downstream model path.

Verification inventory: 244 unit tests + 54 integration tests + 9 mathematical tests = 307 automated tests.
