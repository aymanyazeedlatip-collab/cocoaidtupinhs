# COCO-AID v2.7.0

This release improves navigation, loading clarity, mathematical transparency, Farm Health layout, and default map framing without changing the analytical models.

## Changes

- Extreme Weather has previous and next event arrow controls with wraparound selection.
- Loading is reduced to the rotating COCO-AID logo, circular progress indicator, and rotating farm tips.
- The priority-cell summary remains vertically aligned and contained at all supported widths.
- About includes the core Bayesian, state-transition, suitability, stochastic-weather, Monte Carlo, and expected-utility formulas.
- Climate-conditioned projection maps initially fit the farm polygon with padding and a safe maximum zoom.
