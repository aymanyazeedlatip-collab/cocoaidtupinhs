# COCOAID Phase 11.3 Home Landing Rehaul

## Scope
Frontend-only redesign of the Home tab. Analytical engines, APIs, databases, models, reports, Weather GIS, audio, and existing farm workflows remain preserved.

## Changes
- Full-screen, full-bleed coconut-farm landing background.
- Off-canvas navigation remains hidden until the Menu or Explore Workspace control is selected.
- New hero statement: **Plant Sharper, Harvest Better**.
- Simplified farmer-facing landing content and action hierarchy.
- Removed the white hologram card and made the digital twin float directly over the landing image.
- Preserved the three original orbit-ring elements and their animation definitions.
- Replaced the layered CSS coconut body with an interactive canvas-rendered parametric 3D coconut wireframe.
- Preserved pointer dragging, keyboard rotation, slow automatic rotation, scan line, audio, and reduced-motion behavior.
- Preserved all compatibility DOM IDs required by the existing frontend.

## Version
- Interface: `phase11-agritech-interface-1.3.0`
- Design system: `cocoaid-official-agritech-1.3.0`
