# COCO-AID v2.5.0 - Final Visual Identity

This release overhauls the presentation layer while preserving the audited v2.4.1 analytical behavior.

## Visual identity
- Supplied COCO-AID logo and wordmark integrated across the main application, Weather GIS, favicon, About page, and loading screen.
- Supplied coconut-farm photograph used as a faded landing background.
- Brighter and more saturated green-first agri-tech palette with cyan, blue, amber, violet, and red data accents.
- Restrained page, panel, button, and modal animations with reduced-motion support.

## Loading experience
- Branded full-screen loader.
- Slowly rotating COCO-AID logo.
- Circular loading animation and animated progress sweep.
- Rotating farm-planning tips and project facts.

## About page
- Full project explanation.
- Researcher: Gavrielle Munoz.
- School: Tupi National High School.
- Modules, data foundation, scientific engine, workflow, transparency, and limitations.

## Compatibility
- Existing weather, climate, production, health, pest, rehabilitation, report, database, and assistant functions remain available.
